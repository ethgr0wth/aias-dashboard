# AiAS Dashboard

This is something we built.

AiAS is an interactive concept for an AI agents operating system: a browser-based home for launching tools, arranging workflows, and moving between agent-powered products without the usual dashboard clutter.

The current build includes:

- A polished, desktop-inspired interface
- 24 linked application tiles
- Drag-and-drop icon ordering
- Swipeable application pages
- Customizable static backgrounds
- Local persistence for layout and background preferences
- A restrained use of motion, including edit-mode jiggle feedback

This repository contains the working prototype and its source. It is a product concept rather than a production-ready agent orchestration platform.

## Run locally

```bash
pnpm install
pnpm --filter @workspace/mockup-sandbox run dev
```
